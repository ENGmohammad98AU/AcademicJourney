# مسيرتي الأكاديمية — الإصدار 1.1.0

نسخة محسّنة بصريًا ووظيفيًا من التطبيق الشخصي لإدارة البرامج الجامعية والدرجات.

## الجديد في V5
- تثبيت التطبيق على الوضع الفاتح فقط عبر Color Scheme خاص بالتطبيق.
- تثبيت الصفحة الرئيسية كشبكة 2×2: بطاقتان للجامعات في كل صف.
- استخدام الشعارات الأربعة التي زوّد بها المستخدم داخل بطاقات الجامعات.
- إضافة شريط تنقل سفلي بين الرئيسية والإحصائيات.
- تحسين بطاقات الجامعات والبرامج والفصول والمواد.
- إضافة معدل سنوي مختصر لكل سنة داخل البرنامج.
- تحسين عرض معدل الفصل وحالات المواد.
- إضافة شارة واضحة للحالة: ناجح / راسب / غير مُقيّم.
- تحسين شاشة إدخال الدرجات مع معاينة النتيجة قبل الحفظ ورسالة قواعد الحساب.
- إضافة ملاحظات شخصية قابلة للحفظ لكل مادة.
- إبقاء البحث والفلترة حسب حالة المادة.

## قواعد الدرجات
- الجامعة الافتراضية السورية: وظيفة + امتحان بأوزان مختلفة حسب البرنامج.
- جامعة الأندلس وجامعة اللاذقية وجامعة دمشق: العملي + النظري، وكل قيمة بين 0 و100، والمجموع لا يتجاوز 100.
- النجاح/الرسوب يُحسب من الدرجات المدخلة داخل التطبيق فقط ولا يُستورد من إشارات النجاح في ملفات Word.

## مسار الاستخدام
الرئيسية ← الجامعة ← البرنامج ← السنة/الفصل ← المادة ← إدخال الدرجة والملاحظات

## ملاحظة تقنية
المشروع مبني بـ Kotlin + Jetpack Compose + Room، وقاعدة المقررات المضمنة هي نفس قاعدة V4 المستخرجة من الملفات السبعة السابقة.


## تحديث V6

- تثبيت الواجهة على الوضع الفاتح فقط.
- الصفحة الرئيسية: الجامعات الأربع ضمن شبكة 2×2.
- إضافة منطق **مؤشر التقدم الأكاديمي**:
  - النسبة = عدد المواد الناجحة ÷ إجمالي عدد المواد × 100.
  - النجاح مشتق حصراً من الدرجات المدخلة وقاعدة النجاح الخاصة بالبرنامج.
  - لا يتم استخدام خانة/إشارة «ناجح» المستوردة من ملفات Word.
- إضافة مكوّن **دائرة تقدم** للملخصات السريعة.
- إضافة مكوّن **شريط تقدم أفقي** للتفاصيل داخل الجامعة/البرنامج.
- المنطق يدعم تجميع تقدم الجامعة الافتراضية عبر برامجها، وكذلك حساب تقدم كل برنامج منفرداً.

> ملاحظة تقنية: المشروع مصدر Android Studio ولم يتم تجميع APK داخل هذه البيئة لعدم توفر Gradle wrapper/بيئة بناء Android كاملة.

## تحديث V7

- إضافة دائرة تقدم داخل بطاقة كل جامعة في الصفحة الرئيسية.
- إضافة شريط تقدم تفصيلي داخل صفحة الجامعة والبرنامج والسنة والفصل.
- تعريف «المتبقي للإنجاز» = إجمالي المواد - المواد الناجحة.
- تطوير شاشة الإحصائيات لعرض التقدم الأكاديمي العام والمتبقي.
- إضافة إمكانية تحديث الدرجات المحفوظة من شاشة المادة نفسها.
- إضافة زر لمسح الدرجة مع نافذة تأكيد، مع إبقاء ملاحظات المادة دون حذف.
- عند مسح الدرجة تعود المادة إلى «غير مُقيّمة»، وتتحدث مؤشرات النجاح والتقدم تلقائيًا عبر Room/Flow.
- الإبقاء على البحث والفلاتر داخل الفصل: الكل / ناجح / راسب / غير مُقيّم.
- إضافة فرز على مستوى البرنامج بالكامل لعرض: غير مُقيّمة / راسبة / ناجحة / كل المواد، مع فتح المادة مباشرة من القائمة.
- الواجهة ما زالت فاتحة فقط، والجامعات معروضة ببطاقتين في كل صف.

> ملاحظة: هذه نسخة مصدر Android Studio. لم يتم إنشاء APK أو إجراء build فعلي في هذه البيئة لعدم توفر Gradle wrapper/Android build toolchain كاملة.

## بناء APK عبر GitHub Actions

أضيف في هذه النسخة ملف `.github/workflows/build-apk.yml`.
عند رفع المشروع إلى GitHub وتشغيل Action باسم **Build Android APK**، سيحاول بناء نسخة Debug ورفع الملف الناتج كـ Artifact باسم `AcademicJourney-debug-apk`.
المسار المتوقع داخل الـ Artifact:
`app/build/outputs/apk/debug/app-debug.apk`

## تحديث الإصدار 1.1.0

- جبر أي كسر في المحصلة إلى العدد الصحيح الأعلى لجميع الجامعات، مثل 76.1 إلى 77.
- تطبيق درجة أو درجتي مساعدة تلقائياً في برنامجي الإعلام والاتصال وإدارة الموارد البشرية فقط عند كفايتهما للنجاح.

- حساب حالة الطالب حسب قواعد الترفع الخاصة بكل جامعة وبرنامج، وإظهار «متخرج» بعد نجاح جميع المقررات.

- عرض ساعات كل مقرر في إدارة الموارد البشرية وحساب معدلاته موزونة بالساعات.
- تثبيت PHR601 باسم «مشروع التخرج» وعدد ساعاته 12 ساعة.
- اعتماد مقررات BMN401 وGBL401 وBEC401 وBMK401 وBAC402 كناجحة دون علامة بسبب الانتقال من جامعة اللاذقية.
- اعتماد L1 وL2 وL3 كناجحة دون علامة بناءً على امتحان تحديد مستوى اللغة الإنكليزية.
- إضافة موسيقا أصلية هادئة لفيديو البداية مع زر للكتم والتشغيل.
- تطوير تقرير كل فرع ليشمل شعار الجامعة واسمها، حالة الطالب، المساعدة، الساعات، والمعدلات الفصلية والسنوية.
- الحفاظ على معرّف الحزمة `com.academicjourney.app` وترقية قاعدة Room بترحيل غير هدّام للحفاظ على البيانات.
